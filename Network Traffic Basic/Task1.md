# TryHackMe - Network Traffic Basics

## Task 1: Introduction

### What is Network Traffic Analysis (NTA)?
Network Traffic Analysis (NTA) is the process of capturing, inspecting, and analyzing data as it flows through a network.

**Goal**: Achieve complete visibility into what data is communicated inside and outside the network.

**Important Note**: NTA ≠ Wireshark. Wireshark is just one tool. NTA is a methodology that combines:
1. Correlating logs
2. Deep packet inspection
3. Network flow statistics
4. Specific outlined security goals

### Why NTA Matters?
Essential skill for:
- **SOC L1 Analyst**: Detect anomalies, understand baseline vs deviation
- **Blue Team**: Monitor, detect, respond to threats
- **Red Team**: Understand network behavior to avoid detection

Key skill: Differentiate between "normal" network traffic and traffic that "deviates from baseline".

### Learning Objectives
- Know what network traffic analysis is
- Know what can be observed in network traffic
- Know how to observe network traffic
-  Know typical network traffic sources and flows

### Key Takeaway
NTA is not about tools, it's about mindset. Tools help you see, but analysis helps you understand.
